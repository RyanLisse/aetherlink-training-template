## Scenario and user story

As the fictional Fictional Reconciliation product owner, I want a short accepted intent and
spec for safe status lookup so that the implementer knows the observable
outcome and the public field boundary.

The accepted scope is local fixture data and the existing function signature.
Acceptance here means a human has reviewed the drafts; it does not mean code
is implemented or a service is available.
