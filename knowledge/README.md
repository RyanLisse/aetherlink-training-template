# Knowledge index

Store lessons that can be reused in another session. Name files `YYYY-MM-DD-short-lesson.md` or use a stable topic name for a lesson that evolves. Every note must separate validated facts from hypotheses, identify a reuse owner, and carry a review date. Start with the [knowledge note template](../templates/knowledge-note.md).

| Note | Validation state | Owner | Review date |
| --- | --- | --- | --- |
| `TEMPLATE` | `DRAFT` | `TEMPLATE` | `YYYY-MM-DD` |

The [fictional knowledge note](../examples/fictional-knowledge-note.md) demonstrates the format and is not evidence.
