# Recaps index

Store one concise recap per live session. Name files `YYYY-MM-DD-short-topic.md`, keep the [daily recap template](../templates/daily-recap.md) sections, and link each recap from [progress.md](../progress.md). A recap records observed evidence and open actions; it is not a chronological diary.
