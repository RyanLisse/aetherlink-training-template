# Squad 2 · AI-native SDLC to team delivery

This five-day route starts with the [AI-native SDLC playbook](https://claude.com/blog/the-ai-native-sdlc-playbook) and its [Academy course](https://academy.claude.com/courses/ai-native-sdlc-playbook). Learners first build a shared mental model, then learn agents in n8n and Claude Code, and finally apply the method to one team issue in a local GitLab-shaped workflow.

All data is fictional and local. GitLab, Jira, and Confluence are represented by draft fields only. A human owns scope, review, merge, and publication.

## Five-day route

| Day | Mode | Focus | Visible result |
| --- | --- | --- | --- |
| 1 | Fully guided | AI-native SDLC foundations and playbook map | Shared intent, lifecycle map, and one small plan |
| 2 | Fully guided | SDLC practice with a complete feedback loop | Reviewed local change plan and evidence card |
| 3 | Coached | Build and inspect an agent in n8n | Bounded n8n agent run with evidence |
| 4 | Coached | Build and inspect an agent in Claude Code | Bounded Claude Code agent run with trace and review |
| 5 | Independent with team gate | Own team issue end to end in a GitLab-shaped workflow | Issue brief, implementation evidence, review, and handoff |

Every day is 10:00–16:00. Lunch is 12:00–13:00. Breaks are 11:20–11:35 and 14:00–14:15. The cadence is theory → instruction and demo → individual work → review → break → group practice → human gate → transfer → handoff → reflection.

## Daily branches

Use `squad-2/day-1` through `squad-2/day-5`. Switch before editing. Commit learner evidence on the day's branch. Push only for facilitator review. `main` remains the clean template.

## Shared acceptance rules

- Work from `intent.md`, `progress.md`, and the day's task card.
- Give each learner at least 25 minutes of individual work before group practice.
- Record exact paths, commands, outputs, reviewer, and `OPEN` gaps.
- Keep model, adapter, access, and tool differences as observations.
- Never commit credentials or contact a real GitLab, Jira, or Confluence system.

See each day guide for literal prompts, expected outputs, and checkpoints.
