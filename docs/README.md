# Documentation map

Use [example-prompts.md](example-prompts.md) as starting language for the six phases and for recap, knowledge extraction, and handoff. Adapt prompts to the live outcome and attach evidence; prompts alone are not results.

- [Progress](../progress.md) reports only current verified state.
- [Templates](../templates/session-plan.md) provide the session records.
- [Examples](../examples/fictional-session-recap.md) demonstrate structure with invented data.
